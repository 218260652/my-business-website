# Kota City

Standalone menu website with quantity-aware WhatsApp orders to +27 63 711 5335. No payment is processed on the website. Customers send and confirm orders in WhatsApp.

Menu and prices are in index.html; styles in styles.css; quantities and category filters in app.js. Optimised product photos are in assets/.

Published under /my-business-website/kota-city/ via the existing repository GitHub Pages deployment. Existing root website is preserved.
